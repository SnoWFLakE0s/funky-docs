# Gear Leg
---

## XML ID
`GearLeg-1`

## Part Variables
* **Suspension**: The current length the shock absorber is extended from its compressed state. (Meters)
* **Extension**: How far the landing gear is along to being extended as a percent. (There's definitely a better way to explain this)
