# Gear Leg
---

## XML ID
`GearLeg-1`

## Part Variables
* **Suspension**: The current length the shock absorber is extended from its compressed state. (Meters)
* **Extension**: The current extension of the shock as a percentage of its uncompressed length. (0~1)
