# Cockpit
---

## XML ID
`Cockpit-1, Cockpit-3, Cockpit-4`

## Part Variables
* **Heading**: The current compass heading of the cockpit. (Degrees)
* **PitchAngle**: The current pitch orientation of the cockpit relative to the horizon. Positive values indicate nose-up. (Degrees)
* **PitchRate**: The angular velocity of the cockpit around its lateral axis. (Degrees per second)
* **PosX**: The current east-west coordinate of the cockpit in the game world. (Meters)
* **PosY**: The cockpit block's current altitude above sea level. (Meters)
* **PosZ**: The current north-south coordinate of the cockpit in the game world. (Meters)
* **RollAngle**: The current roll orientation of the cockpit. Positive values indicate a right bank. (Degrees)
* **RollRate**: The angular velocity of the cockpit block around its longitudinal axis. (Degrees per second)
* **Speed**: The current speed of the cockpit, ususally closest to ground speed but may differ slightly. (Meters per second)
* **YawRate**: The angular velocity of the cockpit around its vertical axis. (Degrees per second)
